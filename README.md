# Drop Studio — React + Material UI Recreation

A local React/Vite implementation of the Drop Studio Webflow reference page.

## Stack
- React
- Vite
- Material UI
- Emotion
- Framer Motion
- Manrope

## Run
```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Notes
The page content follows the indexed Drop Studio reference content. The implementation recreates the layout, typography, sections, interactions and motion locally rather than embedding the Webflow page.

Remote/proprietary Webflow image assets are intentionally represented with local CSS/MUI visual treatments so the project remains self-contained.
